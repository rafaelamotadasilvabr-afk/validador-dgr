# Validador DGR XML NF-e

Aplicação HTML estática para leitura de XML de NF-e e triagem inicial de possível DGR.

## Como publicar no Vercel
1. Crie um repositório no GitHub.
2. Envie os arquivos `index.html` e `README.md`.
3. Entre no Vercel.
4. Clique em **Add New > Project**.
5. Selecione o repositório.
6. Framework: **Other**.
7. Build Command: deixe vazio.
8. Output Directory: deixe vazio.
9. Clique em **Deploy**.

## Como usar
1. Baixe os XMLs no Portal EDI.
2. Extraia o ZIP.
3. Abra o site publicado.
4. Selecione todos os XMLs.
5. Clique em **Analisar XMLs**.
6. Exporte CSV.

## Observação operacional
A classificação é uma triagem inicial. Cargas marcadas como VALIDAR ou BLOQUEAR precisam seguir o procedimento oficial da operação.
