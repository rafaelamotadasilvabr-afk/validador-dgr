# Validador DGR | XML NF-e

Site estático para leitura de XMLs de NF-e e triagem operacional de possíveis mercadorias DGR.

## Como publicar no Vercel

1. Crie um repositório no GitHub.
2. Envie `index.html` e `README.md`.
3. No Vercel, clique em **Add New > Project**.
4. Selecione o repositório.
5. Framework: **Other**.
6. Clique em **Deploy**.

## Como usar

1. Baixe os XMLs no Portal EDI.
2. Extraia o ZIP.
3. Abra o site.
4. Selecione os arquivos `.xml`.
5. Clique em **Analisar XMLs**.
6. Exporte o CSV.

## Observação

Os XMLs são processados localmente no navegador. Nenhum arquivo é enviado para servidor.
